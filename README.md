# Energy_Consumption_Prediction
Machine Learning project for household energy consumption prediction
## Overview

This project uses machine learning to predict household energy consumption
using historical electricity consumption data.

## Objective

To develop a regression model that can estimate household energy consumption
from electrical and time-based features.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Project Workflow

1. Data collection
2. Data cleaning and preprocessing
3. Feature engineering
4. Exploratory data analysis
5. Train-test splitting
6. Linear Regression model development
7. Model evaluation
8. Actual vs Predicted visualization

## Model
A Linear Regression model was trained to predict `Global Active Power`
from selected electrical and time-based features.

## Results

| Metric | Value |
|---|---:|
| MAE | 0.0286 |
| RMSE | 0.0432 |
| R² Score | 0.9983 |

## Visualization

The project includes an Actual vs Predicted Energy Consumption plot
to visually evaluate model performance.

## Key Learning

This project provided practical experience in:

- Data preprocessing
- Feature engineering
- Regression modeling
- Model evaluation
- Data visualization
- Working with real-world energy datasets

## Dataset

UCI Individual Household Electric Power Consumption Dataset.

A Linear Regression model was trained to predict `Global Active Power`
from selected electrical and time-based features.
